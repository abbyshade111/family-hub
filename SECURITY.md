# Security policy

## Reporting a problem

Please report security problems privately, through GitHub: open this repository's
**Security** tab and choose **Report a vulnerability**. Only the maintainers see
the report.

Please don't open a public issue or pull request for a security problem.

Include what you found, how to reproduce it, and what someone could do with it.
Don't use real people's data in a report; made-up accounts are fine.

## What to expect

- We aim to acknowledge a report within 7 days.
- We'll keep you updated while it's being fixed, and credit you when the fix is
  released if you'd like.
